# Flick Gesture

Mouse gestures for Chrome and Edge. This repository hosts the extension's website and privacy policy (GitHub Pages), and takes support requests through Issues.

- Website: https://alineapps.github.io/flick-gesture-site/
- Privacy policy: https://alineapps.github.io/flick-gesture-site/privacy.html

右ボタンを押したままマウスを動かして、ブラウザーを操作する Chrome・Edge の拡張機能です。不具合やご要望は Issues へどうぞ。
